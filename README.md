# Dragnev Denis — Portfolio & CV

Personal portfolio focused on IT support, network administration, full-stack development and robotics.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:3000`.

## Featured work

- [Neurovizor Clinic](https://www.neurivizor.eu/ro) — medical booking and administration platform
- [Guvero Store](https://guvero.it/) — Italian e-commerce platform
- [Veri Tenda](https://veritenda.it/) — Italian corporate and lead-generation website

The page is responsive, keyboard-friendly, filterable and includes a print layout for use as a CV.
